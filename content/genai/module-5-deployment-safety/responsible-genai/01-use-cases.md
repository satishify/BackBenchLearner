## Support bots

Handle FAQs, classify tickets, and draft replies with policy grounding.

## Coding agents

Search codebase, propose changes, run tests, and explain fixes.

## Research agents

Collect data from multiple sources, summarize findings, and generate structured notes.

## Automation agents

Execute repetitive operations like report generation, ticket routing, and workflow updates.

## Tip

Start with narrow, high-value use cases where output quality can be measured.
